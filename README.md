# SCI3D – Plataforma Interativa 3D para Ensino de Ciências

Projeto desenvolvido como **Trabalho de Conclusão de Curso (TCC)** com o objetivo de facilitar o aprendizado de **Química, Física e Ciências** através de uma plataforma interativa com recursos visuais e modelos em 3D.

O sistema foi desenvolvido em **PHP com banco de dados MySQL/MariaDB**, oferecendo funcionalidades completas como cadastro de usuários, login, recuperação de senha e área do usuário.

---

## 🎓 Objetivo do Projeto

O principal objetivo do SCI3D é tornar o aprendizado de conteúdos científicos mais visual, intuitivo e acessível, principalmente para estudantes do ensino fundamental e médio.

A plataforma permite que o aluno tenha uma experiência mais dinâmica do que apenas conteúdo teórico, utilizando tecnologia para melhorar o entendimento de conceitos científicos.

---

## 🧪 Áreas abordadas

O sistema foi pensado para auxiliar no ensino de:

* Química
* Física
* Ciências gerais
* Conteúdos escolares que envolvem visualização de estruturas e conceitos

---

## 📂 Estrutura do Projeto

O projeto está organizado em pastas com as seguintes funções:

```
TCCFINAL/
│
├── Login/                → Tela de login, cadastro e conexão com o banco
├── home/                 → Área principal do sistema após o login
├── recupera/             → Sistema de recuperação de senha
├── visitmode/            → Acesso ao sistema como visitante
├── sci3d_db.sql          → Arquivo do banco de dados
└── Certificado 1º lugar projeto TCC.pdf
```

---

## 🗄️ Banco de Dados

O projeto utiliza um banco de dados MySQL/MariaDB que contém:

* Tabela de usuários
* Sistema de recuperação de senha
* Estrutura pronta para login e cadastro

O arquivo do banco está disponível dentro do projeto:

```
sci3d_db.sql
```
